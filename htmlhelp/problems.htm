Problems

You can get hangs and premature errors when running scripts with this program.

  • stdin - some programs hang if their stdin is not redirected
  • stderr - programs writing to stderr can be interpreted as an exception

Example with git, this needs its stdin redirected

( & $env:COMSPEC /C "git log --oneline . <NUL:" ) | Measure-Object

$null | git log --oneline . | Measure-Object

Microsoft's C compiler writes information to stderr, this can abort a pipeline, either redirect or use /nologo

CL 2>&1 .....

CL /nologo .....
As shown, wrapping with $env:COMSPEC lets you put the program in a familiar environment. The goal of this program is collect all output in a single document, whether it came from stdout or stderr, much like a terminal or teletype.
