Configuration

The registry entries are at 'HKLM:\SOFTWARE\rhubarb-geek-nz\MPW Shell'.

Name Type Purpose Example
ToolServer String Command line used to run the PowerShell server PowerShell.exe -NoProfile -NoLogo -NonInteractive -Command $ErrorActionPreference='Stop'; Import-Module 'C:\Program Files\rhubarb-geek-nz\MPW Shell\Modules\rhubarb-geek-nz.ToolServer\0.9.0\rhubarb-geek-nz.ToolServer.psd1' ; Invoke-MPWShell.ToolServer -Protocol 0c63fba6-7c2a-4b72-8de0-b3bd579dedaa
TextLimit DWord Used to set EM_SETLIMITTEXT on the main edit control 0x100000
InitialScript String Used to initialise each Runspace if ($PSStyle) { $PSStyle.OutputRendering = 'PlainText' } ; Import-Module 'C:\Program Files\rhubarb-geek-nz\MPW Shell\Modules\rhubarb-geek-nz.MPWShell\0.9.0\rhubarb-geek-nz.MPWShell.psd1'

Notes

  • 'PowerShell.exe' can be replaced by 'pwsh.exe'
  • The server can be any program as long as it talks using the correct protocol using stdin and stdout
  • The configuration can be overridden in 'HKCU:\Software\rhubarb-geek-nz\MPW Shell'
