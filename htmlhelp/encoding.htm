Encoding

Text encoding follows some rules.

When reading;

  • If it starts with a 2 byte UNICODE BOM then the file is treated as 16-bit UNICODE
  • Otherwise if it starts with the 3 byte UTF-8 BOM then it is treated as 8-bit UTF-8
  • Finally, if neither applies then it uses the process default code page, for example 1252

When writing;

  • If the first character is a BOM it writes it as UNICODE or UTF-8 depending on how it was read
  • Otherwise it uses the process default code page
