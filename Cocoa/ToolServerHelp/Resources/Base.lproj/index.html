ToolServer

ToolServer is an AppleScript tool for PowerShell. It provides the standard 'do script' mechanism for invoking scripts in 3rd party applications.

Apple Script

You can use the following in the Script Editor application. 

tell application "ToolServer"
	do script "$PSVersionTable"
end tell
Likewise from the shell command line 

% osascript -e 'tell application "ToolServer" to do script "Get-Runspace"'



Preferences


The preferences are in ~/Library/Preferences/nz.geek.rhubarb.ToolServer.plist.



	
		

			Name
			Type
			Purpose
		

	
	
		

			ToolServerLaunchPath
			String
			Path to executable
		

		

			ToolServerArguments
			Array
			Arguments passed to the ToolServer process
		

		

			ToolServerEnvironment
			Dictionary
			Values to add to the environment for the ToolServer process
		

	



The defaults are the equivalent of the following XML:



<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
	<key>ToolServerLaunchPath</key>
	<string>/usr/local/bin/pwsh</string>
	<key>ToolServerArguments</key>
	<array>
		<string>-NoLogo</string>
		<string>-NoProfile</string>
		<string>-NonInteractive</string>
		<string>-Command</string>
		<string>
			$ErrorActionPreference = 'Stop' ;
			Import-Module '/Applications/ToolServer.app/Contents/Resources/Modules/rhubarb-geek-nz.ToolServer/rhubarb-geek-nz.ToolServer.psd1' ;
			Invoke-MPWShell.ToolServer -Protocol 0c63fba6-7c2a-4b72-8de0-b3bd579dedaa
		</string>
	</array>
	<key>ToolServerEnvironment</key>
	<dict>
		<key>POWERSHELL_TELEMETRY_OPTOUT</key>
		<string>true</string>
		<key>POWERSHELL_UPDATECHECK</key>
		<string>Off</string>
	</dict>
</dict>
</plist>
