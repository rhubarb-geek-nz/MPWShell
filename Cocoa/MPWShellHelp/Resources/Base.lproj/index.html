MPW Shell

MPW Shell is a GUI for PowerShell. It provides a simple document centric interface where PowerShell commands and script fragments can be run directly from text documents. To execute a command use either ⌘+⏎ or ⌤, it will execute either the selected text or the current line. Pressing ␛ or ⌘+. can be used to cancel a command.

How it works

The program launches PowerShell as a child process running a ToolServer cmdlet that allows it to execute commands and receive the responses. Each document is mapped to a runspace.

A module can also be loaded into each runspace that provides cmdlets to manage the documents.

  • New-MPWShell - to create a new document with optional content
  • Open-MPWShell - to open an existing document
  • Show-MPWShell - to present the user with an alert

Apple Script

You can use the following in the Script Editor application. 

tell application "MPW Shell"
	do script "$PSVersionTable"
end tell
Likewise from the shell command line 

% osascript -e 'tell application "MPW Shell" to do script "Get-Runspace"'

Preferences


The preferences are in ~/Library/Preferences/nz.geek.rhubarb.mpwshell.plist.



	
		

			Name
			Type
			Purpose
		

	
	
		

			ToolServerLaunchPath
			String
			Path to executable
		

		

			ToolServerArguments
			Array
			Arguments passed to the ToolServer process
		

		

			ToolServerEnvironment
			Dictionary
			Values to add to the environment for the ToolServer process
		

		

			InitialScript
			String
			Used to initialise each Runspace
		

	



The defaults are the equivalent of the following XML:



<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
	<key>ToolServerLaunchPath</key>
	<string>/usr/local/bin/pwsh</string>
	<key>ToolServerArguments</key>
	<array>
		<string>-NoLogo</string>
		<string>-NoProfile</string>
		<string>-NonInteractive</string>
		<string>-Command</string>
		<string>
			$ErrorActionPreference = 'Stop' ;
			Import-Module '/Applications/MPW Shell.app/Contents/Resources/Modules/rhubarb-geek-nz.ToolServer/rhubarb-geek-nz.ToolServer.psd1' ;
			Invoke-MPWShell.ToolServer -Protocol 0c63fba6-7c2a-4b72-8de0-b3bd579dedaa
		</string>
	</array>
	<key>ToolServerEnvironment</key>
	<dict>
		<key>POWERSHELL_TELEMETRY_OPTOUT</key>
		<string>true</string>
		<key>POWERSHELL_UPDATECHECK</key>
		<string>Off</string>
	</dict>
	<key>InitialScript</key>
	<string>
		if ($PSStyle) { $PSStyle.OutputRendering = 'PlainText' } ;
		Import-Module '/Applications/MPW Shell.app/Contents/Resources/Modules/rhubarb-geek-nz.MPWShell/rhubarb-geek-nz.MPWShell.psd1'
	</string>
</dict>
</plist>
