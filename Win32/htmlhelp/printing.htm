Printing

PowerShell provides the ability to print text documents, see

  • Get-Printer - for listing available printers and determining their names
  • Out-Printer - print to a specific printer

Example

Get-Printer

Name                           ComputerName    Type         DriverName                PortName        Shared   Published
----                           ------------    ----         ----------                --------        ------   ---------
OneNote (Desktop)                              Local        Send to Microsoft OneNot… nul:            False    False    
Microsoft XPS Document Writer                  Local        Microsoft XPS Document W… PORTPROMPT:     False    False    
Microsoft Print to PDF                         Local        Microsoft Print To PDF    PORTPROMPT:     False    False    
Fax                                            Local        Microsoft Shared Fax Dri… SHRFAX:         False    False    

Get-Content -LiteralPath 'readme.txt' | Out-Printer -Name 'Microsoft Print to PDF'
