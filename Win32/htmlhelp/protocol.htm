Protocol

There is a packet based protocol between client and server consisting. Each packet has 4 DWORD values followed by string data

  • packetType - defined purpose for the package
  • sourceId - component that originated the request
  • targetId - recipient of the packet
  • dataLen - length of payload
  • string body data in UTF-8 encoding

The messages are as follows

Code Purpose Payload
0x80 Echo Request Hello World
0x81 Echo Response Hello World
0x40 Script Reply Output Data
0x41 Reply to create new runspace
0x42 Obituary from a runspace
0x43 Exception occurred on server Printable exception data
0x44 Exception occurred on server Printable exception data
0x45 Command has completed
0x46 Used internally by client Text response from server before protocol start
0x47 Create new document Initial content of document
0x48 Open existing document Full file path to document
0x49 Show an alert Text for the alert
0x50 Excute script Contents of script
0x51 Request to create new runspace Initial script
0x52 Stop the given runspace
0x53 Stop all runspaces associated with this clientId
0x54 Stop the current task
0x55 Attach this client to a runspace Initial script
0x60 Server has died

The protocol allows free-form text to be received prior to establishment of the protocol. This assists solving problems during start up. The protocol officially starts once a known GUID in text followed by CR/LF is received. This GUID is 0c63fba6-7c2a-4b72-8de0-b3bd579dedaa.
