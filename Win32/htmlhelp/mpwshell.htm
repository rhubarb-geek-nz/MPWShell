Text Editor based on Notepad with integrated PowerShell

This is a minimal editor with an integrated command line shell.

The program runs with a background PowerShell process. On pressing Control+Enter, either the selected text or the current line is processed as a script. The responses are captured within the text.

Like Notepad, this has an F5 function to insert the date, the difference is this runs PowerShell's 'Get-Date' and inserts the response.

The 'Exit' menu option does not exit the process directly, it sends 'Exit' as a script to PowerShell.

Each window is paired with its own runspace to provide isolated contexts. The processes finish when all windows are closed.

Use Control+Break to stop a running pipeline. For example, type the following along with Control+Enter.

Start-Sleep 100
This shows the busy cursor while waiting, press Control+Break. 
Exception: The pipeline has been stopped.
Everything else should either be familiar or easy to work out.
